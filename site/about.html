About

This blog is maintained by Kyle Geske, a computer engineer, college web development instructor, and artist from Winnipeg, Manitoba, Canada.

The goal of this website is to document my work developing mobile application using only web technologies. Finished apps will be deployed to the Android Market, and perhaps even to iTunes if I buy an Apple developer license.

All code samples displayed within the posts on this blog are released free and unencumbered software into the public domain. Read The Unlicense for more information.
